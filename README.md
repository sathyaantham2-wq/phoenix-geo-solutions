# Phoenix Geo Solutions — Website

Single-page marketing site for Phoenix Geo Solutions (geological consultancy & international mineral business).

- `index.html` — the whole site (HTML + CSS + JS, no build step)
- `phoenix-bird.webp` — logo mark
- `vercel.json` — clean URLs for Vercel hosting

## Edit contact details
Open `index.html`, find the `CONFIG` block near the bottom (`EDIT YOUR CONTACT DETAILS HERE`) and set phone, WhatsApp number, email, address and LinkedIn URL.

## Deploy
Import this repo in Vercel (Framework: Other, no build command) or run `vercel deploy --prod` in this folder.
